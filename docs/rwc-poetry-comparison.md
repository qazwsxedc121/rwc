# RWC 诗词创作对比实验

题目：**荒原**

## 无 RWC

```
枯井吞下月亮
风在断墙下磨牙

一根白骨坐在田埂上
等雨水认领姓氏

龟裂的河床里
有铁的锈味在爬

晒干的蛙鸣被碾成粉末
撒向更干的天空

夜把最后一粒火
埋进石头的病历

只有仙人掌还醒着
替一封信保留地址
```

**分析**: 意象全在"荒原"的常规语义范围内——枯井、白骨、龟裂、蛙鸣、仙人掌。LLM 沿着最熟悉的路径行走，结果是工整但可预期的现代诗。

## 有 RWC

**注入词** (来自 `stir("荒原", distance 0.3-0.9)`):

| 距离 | 词汇 |
|------|------|
| d=0.3 | 一本正经, 口唇, 感动 |
| d=0.5 | 新材料, 红五月, 访民 |
| d=0.7 | 昆华, html |
| d=0.9 | 自主知识产权, 打電話 |

```
红五月，沙粒灌进一本正经的招商手册
访民在开发区边缘打電話
信号塔的阴影覆盖整片麦地

昆华的风穿过废弃厂房
口唇上贴着新材料研发中心的封条
荒原什么也不解释
翻过围墙，另一片荒原正在公示
它的蓝图不需要自主知识产权
```

**分析**: 机械注入的词（新材料、访民、自主知识产权）迫使 LLM 跳出自然荒漠的框架，重新建构了一个**现代工业废墟**式的荒原——开发区鬼城、废弃厂房、招商手册。这是 LLM 靠自己不会抵达的解读。

## 结论

RWC 的机械词汇扰动成功打破了 LLM 的语义惯性。"荒原"从一个自然意象变成了一个社会批判的载体，仅仅因为几个不相干词汇的强行注入。
